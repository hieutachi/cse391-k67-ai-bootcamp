# 🎓 Khoá học "AI-Accelerated Frontend Developer Bootcamp"

## (HTML5 • CSS3 • JavaScript ES6+ • Bootstrap 5)

## Kế hoạch chi tiết khoá học

> **Đối tượng**: người mới bắt đầu lập trình web, sinh viên CNTT, lập trình viên muốn vững nền tảng Frontend và tăng tốc quy trình cắt giao diện bằng AI.
> **Mục tiêu**: làm chủ HTML5, CSS3, JavaScript ES6+ và Bootstrap 5 để xây dựng giao diện web chuẩn Responsive, đồng thời dùng AI (Gemini / Claude / ChatGPT) như trợ lý đắc lực để phân tích thiết kế, tạo layout, tối ưu CSS và xử lý logic DOM nhanh gấp 3–5 lần.

---

## 📌 Triết lý khoá học (Just-in-Time Learning + Project-Based Learning)

Khóa học KHÔNG dạy "copy-paste code mù quáng" từ AI, mà rèn luyện tư duy làm chủ công cụ qua quy trình **AI-Accelerated Workflow 4 bước**:

| Bước | Nội dung | Ví dụ áp dụng |
|---|---|---|
| **1. Phân tích yêu cầu** (Define UI/UX Requirements) | Đọc bản thiết kế Figma, bóc tách cấu trúc khối (Box Model, Flexbox/Grid), xác định component và trạng thái tương tác | Tách Hero, Doctor Cards, Booking Form từ trang chủ Highland Hospital |
| **2. Soạn thảo nhanh với AI** (Drafting with AI) | Viết prompt chính xác để AI dựng khung HTML semantic, dàn trang Bootstrap 5, viết khung hàm JavaScript | Prompt dựng Navbar responsive kèm ràng buộc cụ thể |
| **3. Phân tích & Thấu hiểu sâu** (Analyze & Deep-Dive) | Đọc–hiểu từng dòng code: vì sao dùng thẻ đó, cách CSS layout vận hành, luồng dữ liệu và sự kiện | Giải thích vì sao dùng `<article>` thay `<div>`, cơ chế flex |
| **4. Tinh chỉnh & Tối ưu** (Refine, Debug & Refactor) | Tự tay chỉnh responsive breakpoints, sửa lỗi hiển thị, chuẩn hoá theo Bootstrap utilities, viết JS dễ bảo trì | Sửa modal vỡ trên mobile, tách hàm render tái dùng được |

### Triết lý cốt lõi

> *"AI không thay thế lập trình viên frontend. Bạn là người hiểu người dùng, quyết định trải nghiệm và chịu trách nhiệm về chất lượng. AI giúp bạn dựng layout nhanh hơn, tìm lỗi nhanh hơn và học công nghệ mới nhanh hơn."*

## 📚 Chương trình học — 12 chương + 1 module bổ trợ, 64 bài

> Mỗi bài học viết ở dạng song ngữ `course-lessons/vi/` và `course-lessons/en/`, gồm: mục tiêu, kiến thức cốt lõi, prompt mẫu dùng AI, phân tích code, bài thực hành gắn với dự án Highland Hospital và phần "bài tiếp theo".

### Chương 1: Chào mừng & AI-Accelerated Workflow (5 bài)
Giới thiệu khoá học, bản đồ công cụ AI cho frontend, quy trình 4 bước (Define → Draft → Analyze → Refine), thiết lập môi trường làm việc (VS Code, Live Server, DevTools), và giới thiệu dự án xuyên suốt Highland Hospital Web Portal.

### Chương 2: Prompt Engineering cho Frontend (5 bài)
Giải phẫu một prompt tốt, prompt cho HTML/CSS, prompt cho JavaScript, prompt cho debug, và buổi workshop thực hành viết prompt cho từng tình huống cắt giao diện thật.

### Chương 3: HTML5 — Chuẩn ngữ nghĩa & Cấu trúc trang (5 bài)
Cấu trúc tài liệu chuẩn (`<!DOCTYPE html>`, `<head>`, `<body>`), thẻ ngữ nghĩa và SEO (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`), Forms & các kiểu Input hiện đại, bảng biểu (`<table>`) và đa phương tiện (`<img>`, `<svg>`).

### Chương 4: CSS3 — Nền tảng & Tư duy dàn trang (5 bài)
Selectors và độ ưu tiên (Specificity), Box Model (Margin, Border, Padding, Content, `box-sizing`), màu sắc–typography–CSS Variables, đơn vị đo (`rem`, `em`, `%`, `vh`, `vw`), và bài thực hành dựng Hero section.

### Chương 5: CSS Layout — Flexbox & Grid (5 bài)
Flexbox (trục chính, trục phụ, căn chỉnh phần tử), CSS Grid căn bản, cách chọn Flexbox hay Grid cho từng loại layout, và bài thực hành dựng lưới Doctor Cards.

### Chương 6: Responsive Web Design & Animation (5 bài)
Media Queries và breakpoints, Mobile-First workflow, hình ảnh và typography linh hoạt, Transitions/Transform/Keyframe Animations, và bài thực hành làm Hero responsive.

### Chương 7: Bootstrap 5 — Grid & Utilities (5 bài)
Cài đặt Bootstrap (CDN & tuỳ biến), hệ thống 12-Column Grid, Utility classes (Spacing, Colors, Flexbox, Border, Shadow, Typography), Button/Badge/Alert, và bài thực hành dựng Services section.

### Chương 8: Bootstrap 5 — Components (5 bài)
Navbar responsive với Hamburger, Cards & List group, Forms (Form Controls, Floating Labels, Validation), Modal & Offcanvas & Accordion, và bài thực hành dựng FAQ + Booking form tĩnh.

### Chương 9: JavaScript ES6+ — Cú pháp & Dữ liệu (5 bài)
`let`/`const`, Template Literals, Arrow functions, Destructuring, Spread/Rest, Array Methods cốt lõi (`map`, `filter`, `reduce`, `find`, `forEach`), JSON handling, và bài thực hành render danh sách bác sĩ từ dữ liệu mẫu.

### Chương 10: DOM & Event Handling (5 bài)
Truy vấn và thao tác DOM (`querySelector`, `classList`, tạo/xoá phần tử), sự kiện (click, input, submit, change, scroll; Event Delegation, `preventDefault`), Form validation phía client, `localStorage`, và bài thực hành bộ lọc bác sĩ theo chuyên khoa.

### Chương 11: Async JavaScript & API (5 bài)
Fetch API / Async-Await, Mock REST API, trạng thái Loading (Spinner) và xử lý lỗi, luồng đặt lịch đa bước (Multi-step Booking), và bài thực hành hoàn thiện luồng đặt lịch khám.

### Chương 12: Dự án Highland Hospital & Component Thinking (6 bài)
Tổng quan dự án và phân tích Figma, dựng Landing Page bằng Bootstrap 5, tương tác JavaScript (lọc bác sĩ, đặt lịch, validate, Modal), Admin Dashboard (tìm kiếm, lọc trạng thái, cập nhật lịch hẹn, lưu LocalStorage), tối ưu hiệu năng & kiểm tra Responsive, và tư duy component hướng tới React/Vue/Angular cùng định hướng nghề nghiệp.

### Module bổ trợ 13: Thực hành Prompt Engineering cho Frontend Developer (3 bài)
Module tăng tốc dành riêng cho frontend developer: khung prompt chuẩn phân tích giao diện Figma (bóc tách layout, grid, component, trạng thái, responsive), khung prompt chuẩn sinh code Bootstrap 5 từ đặc tả kèm ràng buộc để code dùng được ngay, và một lab tổng hợp "Figma → Bootstrap" trong một phiên làm việc. Bộ prompt mẫu chuẩn đặt tại `templates/prompt-kit-figma-to-bootstrap.md`. Học viên nên học module này sau chương 8 (đã đủ nền Bootstrap) hoặc sau toàn khoá như bước thực chiến cuối cùng.

## 🎓 Chuẩn đầu ra

Sau khoá học, bạn có thể:

1. Viết HTML5 chuẩn ngữ nghĩa (Semantic Web, SEO, Accessibility) và CSS3 (Box Model, Flexbox, Grid, CSS Variables, Animations).
2. Dựng giao diện Responsive chuyên nghiệp với Bootstrap 5: 12-Column Grid, Flex utilities, Breakpoints, Navbar, Modal, Offcanvas, Accordion, Cards, Forms.
3. Lập trình tương tác bằng JavaScript ES6+: DOM Manipulation, Event Handling, Array Methods, `localStorage`, Form Validation.
4. Gửi–nhận dữ liệu JSON bằng `Fetch API` / `Async–Await` với trạng thái Loading và xử lý lỗi.
5. Áp dụng AI-Accelerated Workflow 4 bước để phân tích thiết kế, tạo layout, tối ưu CSS và debug nhanh gấp 3–5 lần — nhưng vẫn hiểu từng dòng code và review được output của AI.
6. Hoàn thiện **Highland Hospital Web Portal**: Landing Page (Hero, dịch vụ, bác sĩ, đánh giá, footer), luồng đặt lịch đa bước có validate, và Admin Dashboard (metrics, data table, tìm kiếm/lọc/cập nhật trạng thái) — triển khai lên GitHub Pages / Vercel.
