Capstone project

Dự án tốt nghiệp: Highland Hospital Web Portal

Một bệnh viện quốc tế giả định: ba trang, một luồng đặt lịch đa bước, một bảng quản lý lịch hẹn. Không server, không database, nhưng vẫn giống hệ thống thật.

Phạm vi

Ba trang bạn sẽ xây

Landing Page

index.html — Hero, 6 dịch vụ, 8 bác sĩ, 6 đánh giá, lịch sử khám — dựng bằng Bootstrap 5.

Đặt lịch khám

booking.html — Form đa bước: chọn khoa → bác sĩ → ngày giờ → thông tin → xác nhận.

Admin Dashboard

admin.html — Thẻ số liệu, bảng lịch hẹn, tìm kiếm, lọc và đổi trạng thái.

Design language

Màu, font và khoảng cách

#0D6E63Primary #B45309Accent #3B82F6Info #22C55ESuccess #EF4444Error Be Vietnam ProHeading InterBody

Spacing theo thang 4pt, bo góc 4–16px, bóng đổ rất nhẹ — đó là lý do giao diện trông "có nghề" dù chỉ dựng bằng Bootstrap.

Đánh giá

Bạn sẽ nộp gì

  • Buổi 1–5: môi trường chạy được bằng Live Server, viết được prompt có cấu trúc.
  • Giữa kỳ: Landing Page dựng từ Figma, responsive đủ 3 breakpoint.
  • Cuối kỳ: form đặt lịch đa bước + Admin Dashboard có tìm kiếm, lọc, đổi trạng thái.
  • Bonus: gọi mock API bằng Fetch, chuyển 2 trang sang React (Vite + TypeScript).

Ràng buộc

Không dùng CSS framework nào ngoài Bootstrap 5 ở chương 7–8; JavaScript thuần cho tới chương 12; mọi đoạn code do AI sinh ra phải giải thích được khi chấm bài.
