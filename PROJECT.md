# AI-Accelerated Frontend Developer Bootcamp
## (HTML5 • CSS3 • JavaScript ES6+ • Bootstrap 5)

## 1. Tổng quan khóa học (Course Description)
Bạn muốn tự tay xây dựng các giao diện website hiện đại, chuẩn Responsive và có độ tương tác cao nhưng chưa biết bắt đầu từ đâu? Bạn muốn tối ưu hóa tốc độ cắt giao diện và code Frontend bằng sức mạnh của AI? Chào mừng bạn đến với **AI-Accelerated Frontend Developer Bootcamp** — khóa học tập trung trang bị nền tảng lập trình Frontend vững chắc từ cốt lõi với **HTML5, CSS3, JavaScript hiện đại (ES6+)** và thư viện UI hàng đầu **Bootstrap 5**.

Khóa học được thiết kế theo triết lý **Just-in-Time Learning** kết hợp phương pháp **Project-Based Learning (Học qua dự án thực tế)**: Bạn sẽ không học lý thuyết rời rạc mà đi thẳng vào xây dựng hoàn chỉnh giao diện hệ thống y tế & đặt lịch khám trực tuyến **Highland Hospital**.

Đồng thời, bạn sẽ làm chủ quy trình làm việc chuẩn của một Senior Frontend Developer khi ứng dụng **AI (Gemini / Claude / ChatGPT)** làm trợ lý đắc lực để phân tích thiết kế (Figma), tạo layout nhanh chóng, tối ưu hóa CSS và xử lý logic DOM tương tác mượt mà.

---

## 2. Phương pháp học tăng tốc với AI (The AI-Accelerated Workflow)
Khóa học không dạy bạn "copy-paste code mù quáng" từ AI, mà rèn luyện tư duy làm chủ công cụ thông qua quy trình 4 bước:

1. **Phân tích yêu cầu (Define UI/UX Requirements):** Đọc bản thiết kế Figma, bóc tách cấu trúc khối (Box Model, Flexbox/Grid), xác định các component và trạng thái tương tác.
2. **Soạn thảo nhanh với AI (Drafting with AI):** Viết câu lệnh (prompt) chính xác để AI hỗ trợ dựng khung mã nguồn HTML semantic, dàn trang Bootstrap 5 và viết khung hàm JavaScript.
3. **Phân tích & Thấu hiểu sâu (Analyze & Deep-Dive):** Đọc - hiểu chi tiết từng dòng code: tại sao dùng thẻ HTML đó, cách CSS layout vận hành, luồng dữ liệu và sự kiện trong JavaScript.
4. **Tinh chỉnh & Tối ưu (Refine, Debug & Refactor):** Tự tay chỉnh sửa responsive breakpoints, sửa lỗi hiển thị, chuẩn hóa CSS theo Bootstrap utilities và viết mã JavaScript tối ưu, dễ bảo trì.

## 3. Đối tượng học viên (Who This Course Is For)
* **Người mới bắt đầu (Beginners):** Chưa từng lập trình hoặc muốn bắt đầu học bài bản từ nền tảng cốt lõi của Web (HTML/CSS/JS).
* **Sinh viên CNTT / Lập trình viên muốn vững Frontend cơ bản:** Củng cố tư duy dàn trang, nắm chắc cơ chế DOM, Event Loop, Async/Await và responsive web trước khi bước lên các framework phức tạp.
* **Người muốn tăng tốc độ làm việc với AI:** Nắm bắt kỹ năng giao tiếp với AI để cắt giao diện Figma sang mã nguồn thực tế nhanh gấp 3–5 lần.

## 4. Mục tiêu đạt được sau khóa học (What You'll Learn)
* **Làm chủ nền tảng Web cốt lõi:** Viết mã HTML5 chuẩn ngữ nghĩa (Semantic Web, SEO, Accessibility), làm chủ CSS3 (Box Model, Flexbox, Grid, CSS Variables, Animations).
* **Xây dựng giao diện Responsive chuyên nghiệp với Bootstrap 5:** Thành thạo hệ thống 12-Column Grid, Flex utilities, Spacing, Breakpoints và các UI Components sẵn có (Navbar, Modal, Offcanvas, Dropdown, Accordion, Cards, Tables, Forms).
* **Lập trình tương tác giao diện với JavaScript ES6+:** Thành thạo DOM Manipulation, lắng nghe và xử lý sự kiện (Event Handling), thao tác mảng/đối tượng dữ liệu, lưu trữ cục bộ (`localStorage`) và xử lý form validation.
* **Tích hợp API và Bất đồng bộ:** Gửi nhận dữ liệu JSON động bằng `Fetch API` / `Async - Await`, mô phỏng hệ thống gọi dữ liệu thực tế và hiển thị dữ liệu lên bảng/thẻ.
* **Hoàn thiện Dự án thực tế (Highland Hospital Web Portal):**
  * Xây dựng Landing Page đầy đủ: Hero banner, Danh mục dịch vụ, Bộ lọc danh sách bác sĩ, Đánh giá, Footer.
  * Xây dựng luồng Đặt lịch khám đa bước (Multi-step Appointment Booking Form) có validate dữ liệu.
  * Xây dựng Dashboard Quản trị & Bác sĩ: Thẻ thống kê (Metrics Cards), Bảng quản lý lịch hẹn (Data Table với tính năng Tìm kiếm, Lọc trạng thái, Cập nhật trạng thái cuộc hẹn).

## 5. Ngăn xếp công nghệ & Kiến thức chi tiết (Tech Stack & Curriculum)

### Module 1: HTML5 Chuẩn ngữ nghĩa & Cấu trúc trang
* Cấu trúc tài liệu web tiêu chuẩn (`<!DOCTYPE html>`, `<head>`, `<body>`).
* Thẻ ngữ nghĩa phục vụ cấu trúc và SEO: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`.
* Biểu mẫu (Forms) & Các kiểu Input hiện đại, bảng biểu (`<table>`), nhúng đa phương tiện (`<img>`, `<svg>`).

### Module 2: CSS3 Hiện đại & Tư duy Dàn trang
* **Nền tảng:** CSS Selectors, Độ ưu tiên (Specificity), Kế thừa, Box Model (Margin, Border, Padding, Content, `box-sizing`).
* **Bố cục nâng cao:** CSS Flexbox (trục chính, trục phụ, căn chỉnh phần tử) & CSS Grid căn bản.
* **Responsive Web Design (RWD):** Media Queries, đơn vị đo tương đối (`rem`, `em`, `%`, `vh`, `vw`), Mobile-First workflow.
* Hiệu ứng chuyển động: CSS Transitions, Transform, Hover States và Keyframe Animations.

### Module 3: Bootstrap 5 — Tăng tốc xây dựng giao diện
* Cài đặt & Cấu hình Bootstrap (CDN & Custom CSS override).
* Hệ thống lưới (Bootstrap 12-Column Grid System, Containers, Rows, Cols, Breakpoints: `sm`, `md`, `lg`, `xl`, `xxl`).
* Bootstrap Utility Classes: Spacing (`m-*`, `p-*`), Colors (`bg-*`, `text-*`), Flexbox utilities, Border, Shadow, Typography.
* Tích hợp & Tùy biến Components:
  * Navigation: Navbar responsive với Hamburger Toggle, Nav & Tabs.
  * Content Containers: Cards, Badges, Alert messages, List group.
  * Interactive UI (kết hợp Bootstrap JS): Modals, Offcanvas (Mobile menu / Filter drawer), Accordion (FAQ), Dropdowns, Toasts/Popovers.
  * Forms: Form Controls, Floating Labels, Form Validation styles, Input Groups.

### Module 4: JavaScript ES6+ & Thao tác DOM tương tác
* **Cú pháp hiện đại:** `let`/`const`, Arrow functions, Template Literals, Destructuring, Spread/Rest operator.
* **Thao tác dữ liệu:** Array Methods cốt lõi (`map`, `filter`, `reduce`, `find`, `forEach`), JSON handling.
* **DOM Manipulation:** Truy vấn phần tử (`querySelector`, `querySelectorAll`), thay đổi nội dung/style/class (`classList.add/remove/toggle`), tạo và xóa phần tử động.
* **Event Handling:** Sự kiện click, input, submit, change, scroll; Event Delegation và `preventDefault()`.
* **Quản lý dữ liệu Client-side:** Xử lý dữ liệu động, lưu trữ trạng thái giao diện và danh sách lịch hẹn với `localStorage`.
* **Async JS & Fetch API:** Gọi API giả lập (Mock REST API/JSON), hiển thị trạng thái Loading (Spinner), Xử lý lỗi và Render dữ liệu ra giao diện.

### Module 5: Dự án thực tế — Xây dựng Highland Hospital Web Portal
* **Giai đoạn 1:** Phân tích bản thiết kế Figma, lập sơ đồ khối giao diện.
* **Giai đoạn 2:** Dựng khung Semantic HTML và dàn trang toàn bộ giao diện bằng Bootstrap 5.
* **Giai đoạn 3:** Viết mã JavaScript xử lý tương tác (Lọc bác sĩ theo chuyên khoa, Đặt lịch hẹn, Validate Form, Bật/Tắt Modal).
* **Giai đoạn 4:** Xây dựng trang Admin Dashboard (Tìm kiếm cuộc hẹn, Lọc theo trạng thái, Xóa/Duyệt lịch hẹn, Lưu vào LocalStorage).
* **Giai đoạn 5:** Tối ưu hóa hiệu năng, kiểm tra Responsive đa thiết bị và Triển khai (Deploy) website lên GitHub Pages / Vercel.
